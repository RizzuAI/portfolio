Chi sono

Costruisco infrastrutture per agenti che prendono decisioni reali.

Lavoro come AI Agent Architect presso Hermes Agent. Il mio lavoro non è prompt engineering: è disegnare sistemi dove gli LLM diventano componenti affidabili all'interno di pipeline produttive. Memoria, tool calling, fallback, osservabilità. Ogni agente è un sistema distribuito.

01 — APPROCCIO

Architettura prima del prompt

Un agente non è un modello. È il sistema che lo circonda: routing, memoria, validazione, retry policy. Progetto l'architettura prima di scrivere una sola istruzione.

02 — PRODUZIONE

Agenti che vivono in produzione

Ogni agente che spedisco ha metriche, tracing, guardrails e fallback. Niente demo. Niente "funziona sul mio terminale". Roba che gira sotto carico.

03 — FILOSOFIA

Strumenti piccoli, composizione grande

Preferisco molti agenti specializzati che collaborano a un solo mega-agente. Orchestrazione leggera, responsabilità chiare, debug possibile.

04 — CONTESTO

Sviluppo in pubblico

Tutto il mio lavoro esplorativo è su GitHub. Issue, README, esperimenti falliti. Costruisco in pubblico perché è il modo più veloce per imparare dagli altri.

Multi-Agent Orchestration 2024

Hermes Scout

Sistema multi-agente per ricerca di mercato autonoma. Quattro agenti specializzati (ricerca, estrazione, sintesi, validazione) orchestrati con un supervisor che gestisce fallback e conflitti. Memoria condivisa su pgvector, tracing completo con OpenTelemetry.

Python LangGraph pgvector OpenTelemetry FastAPI
Tool Calling · RAG 2024

Atlas Memory

Layer di memoria persistente per agenti long-running. Distinzione tra memoria episodica (sessione), semantica (conoscenza) e procedurale (tool appresi). Recupero ibrido keyword + vettoriale, con auto-consolidamento dei fatti ogni N interazioni.

TypeScript Postgres pgvector BM25 Redis
Guardrails · Safety 2023

Sentinel Policy Engine

Motore di policy dichiarative per validare output degli agenti prima dell'esecuzione dei tool. Regole in YAML, valutazione in pipeline, blocking opzionale con richiesta di approvazione umana. Usato in produzione su 6 agenti Hermes.

Python Pydantic YAML OPA Webhook
