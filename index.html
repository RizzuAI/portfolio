About Me

Come costruisco sistemi AI autonomi

Approccio

Progetto agenti come sistemi distribuiti: ogni componente ha responsabilità definite, stati tracciabili e capacità di recovery automatica. Niente black box, tutto osservabile e debuggabile.

Stack

Python per core logic, Rust per componenti critiche di performance, Go per orchestrazione distribuita. LLM via API e self-hosted. Vector DB per memoria semantica, Redis per stato temporaneo.

Filosofia

Gli agenti devono essere prevedibili prima che intelligenti. Parto da guardrails rigidi, poi allento dove i dati lo giustificano. La sicurezza è feature, non afterthought.
