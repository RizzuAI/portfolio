Chi sono

Costruisco sistemi che pensano, agiscono e si adattano. Non script. Non automazioni banali. Agenti veri.

01 / Filosofia

Dal tool all'agente

La maggior parte dell'AI oggi è un wrapper glorificato. Io progetto architetture dove il modello ha memoria, contesto, capacità di pianificare e correggersi. Ogni agente è un sistema distribuito con stati, retry logic e osservabilità integrata.

02 / Esperienza

4 anni su larga scala

Ho scalato infrastrutture da zero a migliaia di agenti concorrenti. Ho debuggato race condition a 3 del mattino. Ho scritto il 90% del codice che uso: dal framework di orchestrazione agli strumenti di monitoring, passando per i protocolli di comunicazione agent-to-agent.

03 / Stack

Python, Rust, e molto codice proprietario

Non seguo hype. Uso Python per la velocità di iterazione, Rust quando serve performance critica. Il resto è architettura: message queues, vector stores, grafi di esecuzione. Zero dependencies inutili, zero framework che non capisco fino in fondo.
