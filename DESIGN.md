# DESIGN.md — Portfolio Pierluigi Rizzu

Surface: Decide/Learn.

Palette: warm paper `#f7f3ec`, ink `#1f2a24`, muted `#6f756d`, line `#d8d0c3`, one accent `#8a4f24` reserved for links, focus, buttons.

Typography: system-ui stack, tight display at 52→30px, section titles at 28→24px, readable body 17→16px, captions 13px. No imported default webfont.

Space: max width 980px, sections 96px desktop / 70px mobile, asymmetric intro layout, border-only cards, timeline rows.

Components: compact sticky nav, flat pill buttons, project list with stack tags, bilingual toggle, no icons-as-decoration.

Motion: restrained entry transforms, visible fallback opacity, reduced-motion support, no parallax.
